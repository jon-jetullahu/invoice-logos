# Visa fee provenance and calculation cautions

Source: private message from Dritan, Visa country coverage contact, shared by user. This is an **informal non-binding estimation**; direct Visa charges and estimated third-party costs are mixed. No official Visa contract or tariff schedule supplied.

## Derived illustrative scenarios (USD)
- **Issuing Affiliate**: 50k licence + 50–200k processor + 50–200k card management + 10–50k production + 5k configuration + 1.5–3k BIN + 47.5k assumed 12-month project fees + 20k first-year quarterly fixed = **234k–575.5k**.
- **Issuing Principal**: same with 80k licence = **264k–605.5k**.
- **Issuing + Acquiring Principal**: 205k combined licences + 50–200k processor + 50–200k card management + 20–100k gateway + 10–50k production + 5k config + 1.5–3k BIN + 47.5k project + 20k annual fixed = **409k–829.5k**.

These are **NOT all-in estimates**. Exclude acquiring platform, POS terminals, fraud, card transaction costs, sponsorship, processing recurring fees, compliance, integration, CBS, taxes. Potential duplicate components must be reviewed.

Visa project example: 5 × $2,500 + 7 × $5,000 = $47,500 if it lasts 12 months. No evidence that it necessarily lasts 12 months or is charged only once for both activities.

Do not mix USD and EUR without explicit FX date/rate. Do not add a 5-year vendor total to its annual components.
