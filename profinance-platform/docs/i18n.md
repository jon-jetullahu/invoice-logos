# Languages: English / Shqip

The platform is fully bilingual. Switch the language with the selector in the top bar. The choice is remembered in the browser; `?lang=sq` or `?lang=en` in the URL also sets it. Without either, the browser language decides (Albanian browsers open in Shqip).

## What is translated

| Layer | Treatment |
|---|---|
| All UI text (navigation, labels, tables, banners, charts, board report) | `src/app/sq.ts`: 976 entries, keyed by the English source string |
| Engine messages (statuses, blockers, verdict reasons, integrity checks) | The engine emits language-neutral **codes and parameters**; `src/app/messages.tsx` renders them in either language |
| Codes (statuses, source types, verdicts) | Translated through the same dictionary |
| Numbers | English `€1,234.5` · `€9.91m` · `12.3%`; Albanian `1 234,5 €` · `9,91 mln €` · `12,3%` |
| Period labels | `Pre-op / Y1…Y10` ↔ `Para nisjes / V1…V10` |
| Research tables | Albanian columns: `hr_roles.role_sq`, `cost_database.item_sq`, `cbk_requirements.requirement_sq`, `sector_indicators.label_sq`, `kosovo_bank_salary_evidence.role_or_scope_sq` (generated by `scripts/add_sq_columns.py`) |
| Memos | Albanian versions: CBK pre-application questions, readiness report, org chart (`*.sq.md`). The other memos are marked "Vetëm në anglisht" |
| Exports | The Excel workbook, CSV header and board report follow the selected language |

**Not translated, by design:**

* Free-text research notes and source titles stay in their original language. Their columns are labelled "Notes (source language)" or "Shënime (gjuha e burimit)".
* Legal and statute titles stay as they are.
* Technical field names in the Excel ledger sheets stay in English.

## Quality controls

* `tests/i18n.test.ts` fails if any UI string, engine label or status code lacks an Albanian translation.
* The same test fails if a translation drops a `{placeholder}` or `**bold**` / `` `code` `` markup.
* `scripts/i18n-dump.ts` lists any new strings that need translation.
