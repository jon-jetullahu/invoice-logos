# Data dictionary: research/

| File | Grain | Key fields | Notes |
|---|---|---|---|
| `institutions.csv` | one row per institution (current and historical) | institution_id, aliases_and_predecessors, entity_type (subsidiary / branch), status_2026, first/last_operating_year, verification_status | Feeds the coverage matrix |
| `document_registry.csv` | one row per discovered document | document_id, institution_id, fiscal_year (verify on the title page), url, retrieval_status, local_path, sha256, audit_status, extraction_status | Updated in place by the collector |
| `retrieval_log.csv` | one row per HTTP attempt | timestamp_utc, method (direct / wayback_cdx / wayback), http_status, outcome, error_class | Append-only |
| `coverage_matrix.csv` | institution × fiscal year | status ∈ {VERIFIED_EXTRACTED, DOWNLOADED_UNVERIFIED, NEEDS_MANUAL_REVIEW, FOUND_LINK_ONLY, BLOCKED, NOT_PUBLIC, NOT_YET_LOCATED} | Generated by `build_coverage.py`; never hand-edited |
| `historical_financials.csv` | one observation | metric_id, period_end, stock_or_flow, value, unit (EUR / EUR_thousand / EUR_million / EUR_billion / count / fraction), source_document_id, source_page, source_type, audit_status, restatement_version, confidence | Units are never mixed. Restatements are new rows with a higher version |
| `quality_checks.csv` | one check result | check, subject, result (PASS / FAIL / NOT_TESTABLE) | A = L + E identity, provenance, units, restatement lineage |
| `sector_indicators.csv` | one sector indicator | value, unit, source, confidence | Search-derived |
| `cbk_legal_sources.csv` | one legal instrument | publication/effective date, status, superseded_by, retrieval_status | Effective-dated |
| `cbk_requirements.csv` | one requirement | binding_status (STATUTORY / REGULATORY / SUPERVISORY_EXPECTATION / UNKNOWN), verification_status, source_id, article, threshold_value, stage, compliance_status | Mandatory vs expectation kept separate |
| `hr_roles.csv` | one role | requirement_status, CBK approval, independence, outsourceable, driver (fixed / per_branch), FTE by scenario and year, gross monthly salary low/base/high, salary_source_status | Salaries are estimates |
| `kosovo_bank_salary_evidence.csv` | one observed data point | observed_or_estimated, confidence | Observed data only |
| `cost_database.csv` | one cost line | low/base/high, basis, timing, accounting (opex / capex), engine_module (generic / cbs / visa / reference), vat_irrecoverable, islamic_only | `reference` rows are never added |

Glossary of source types: MANAGEMENT_PROVIDED, VENDOR_ESTIMATE, PRIVATE_PRELIMINARY_ESTIMATE, CBK_REPORTED_UNVERIFIED, SECONDARY_SOURCE, MARKET_BENCHMARK_SEARCH, ESTIMATE_NOT_MARKET_VERIFIED, UNSOURCED_ASSUMPTION, DEMO_PRESET, DERIVED.
